**Автоматический перевод подставляемых значений под другие языки в формате (JSON)**

> Небольшой инструмент-командная утилита, которая помогает поддерживать локализации: находит недостающие ключи в JSON-файлах локалей и автоматически предлагает / записывает переводы.

---

## Особенности

* Поиск и сравнение JSON-файлов локалей (например, `en.json`, `ru.json`) для обнаружения отсутствующих ключей.
* Автоматическое получение переводов для отсутствующих значений (через подключаемые провайдеры/модуль перевода).
* Возможность применять переводы автоматически или выводить их на проверку перед записью.
* Конфигурируемая папка локалей и правила записи (см. `tranlsate-diff.config.js`).


### Типичный сценарий

1. Инструмент читает базовую (source) локаль, например `locales/ru.json`.
2. Находит отличающиеся или отсутствующие ключи в целевых локалях (`locales/en.json`, `locales/de.json`).
3. Получает перевод для недостающих строк (автоматически или по подтверждению).
4. Записывает / обновляет целевые JSON-файлы.

## Конфигурация

Файл конфигурации по умолчанию: `translate-diff.config.js`.
В нём обычно настраивают:

* путь к папке локалей (`locales`),
* базовую (source) локаль,
* список целевых локалей,
* провайдер переводов / токены API (если требуется)
